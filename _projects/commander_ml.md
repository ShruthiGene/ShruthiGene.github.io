Commander ML is an interactive deck-building coach for new Magic: The Gathering Commander players. It turns beginner preferences such as colors, speed, flavor, strategy, budget, table power level, and complexity into three starter deck archetypes.

The tool explains each suggestion in plain language: what the archetype means, how it usually wins, what card categories to invest in first, suggested commanders, common creature types, sample cards, and beginner safety checks.

**Links**

- [Open the web app](https://shruthigene.github.io/Commander_ML/)
- [View the GitHub repository](https://github.com/ShruthiGene/Commander_ML)

**Built with**: HTML, CSS, JavaScript, Python prototype logic, and heuristic recommendation rules.
