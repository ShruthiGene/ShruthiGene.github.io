A small web app for generating calming white noise directly in the browser. It is meant as a lightweight utility for focus, background ambience, or sleep without needing a separate app.

The project is a practical interactive tool and a clean example of using browser audio features for a simple user-facing experience.

**Links**

- [Open the web app](https://shruthigene.github.io/white-noise-gen/)
- [View the GitHub repository](https://github.com/ShruthiGene/white-noise-gen)

**Built with**: web audio, HTML, CSS, and JavaScript.
